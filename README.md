A theme I've been working on that focuses on actual photos and scans.

Currently supports the retroachivements consoles for the system list but I will be adding more if there is interest.

Supports 16:9, 16:10, 21:9, and 1:1 displays, tested and optimized for HDTV, Steamdeck, Ultrawide PC, and fold phones such as the Oneplus Open, however the 1:1 theme should work on 4:3, and 21:9 should support most slate style phones.
